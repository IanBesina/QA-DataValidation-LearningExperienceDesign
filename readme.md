**A.** This activity aids IT learners in developing a public portfolio focused on basic manual QA Testing and data validation using simple SQL queries.

## V. AI Generation Prompt (`webapp-generation-prompt.txt`)

```text
Write a complete, single-file PHP script (with embedded HTML, CSS, and vanilla JavaScript) for a form titled "Kara David's Wish Note" (use this for the <title> and an <h2> heading).

UI and Design:
1. Create a polished, professional, and mobile-responsive layout using a flat-blue color theme. Use a centered card layout with a subtle drop shadow on a light gray background. Style the input fields, buttons, and success messages cleanly.
2. Form Fields: The form must have the following inputs with exact maxlength properties:
  - "Target's First Name" (name: FirstName, mandatory, 30 chars max)
  - "Target's Last Name" (name: LastName, mandatory, max 30 chars)
  - "Target's Government Position" (name: GovPosition, mandatory, max 20 chars)
  - "Target's Location" (name: Location, optional, max 40 chars)

Front-End Logic (The Modal): 
3. When the user clicks the submit button, use vanilla JavaScript to intercept the submission (e.preventDefault()). Display a custom-styled, centered modal overlay that asks the user to "Verify Target Data". The modal must display the values entered for all four fields (including Location). Include a "Cancel" button to close the modal, and a "Confirm & Send" button that bypasses the interception (form.submit()) to send the POST data.

Backend Logic & The Intentional Flaw: 
4. At the top of the file, establish a local mysqli connection to a MariaDB database using $servername = "localhost", $username = "root", no password, and $dbname = "birthday_wishnote".
When the POST request is received, capture all four variables from the form. However, intentionally introduce a flaw in the SQL query: write an INSERT INTO statement targeting the main_corrupt_politicians table, but completely omit the Location column in both the SQL string and the bind_param function. It should ONLY insert FirstName, LastName, and GovPosition. Upon successful execution, display a styled success message above the form saying: "Success! The wish note has been sent." Include a fallback error message if the query fails to prepare. Add clear comments explaining the intentional database insertion flaw.
```

### Defect Observed
The Location field is displayed in the form and verification modal, but the SQL INSERT statement omits the Location column and its corresponding bound parameter. Consequently, the submitted location is not saved to the database. 

*This intentional defect demonstrates why database testing must verify stored values, not merely rely on a front-end success message.*

### Conclusion
The application successfully accepted and submitted the test data. However, the database verification revealed that the Location value was not persisted. The form submission test succeeded, while the Location persistence requirement was not met.
